# 전용 기수 모델 굽기 (Tripo → 기마 모델)

Tripo에서 받은 T자세 모델(mixamo 뼈대)을 기마 모델(`cavalry.glb`)의 말 탄 기본 자세로 굽고, 기마 뼈 번호로 다시 묶어 `public/assets/models/riders/<id>.glb`로 저장합니다.

1. `bake.js`(브라우저, three.js): 뼈마다 원본 방향 → 기마 기수 방향 회전(몸통은 두 축 맞춤, 팔다리는 최단 회전)으로 정점을 옮기고, 가중치를 같은 이름의 기마 뼈로 옮깁니다. 뼈대 없는 모델은 비슷한 모델(donor)의 가장 가까운 점에서 가중치를 빌립니다.
2. `assemble.py`: 위치 int16 · 법선 int8 · UV uint16 · 뼈 uint8로 양자화(KHR_mesh_quantization)하고 텍스처를 줄여(기본색 1024 · 법선 512 JPEG) GLB로 묶습니다.

`tianming-map.txt`: 2026.10.17 천명 무장 16명 원본 파일 ↔ 무장 id. 셋째 칸이 있으면 그 모델에서 가중치를 빌린다(유비: 뼈대 없음, 조운: 가중치가 전부 엉덩이뼈). 역바인드 뼈대가 Y축으로 돌아간 파일은 bake.js가 자동으로 바로잡는다.

## 부품으로 나뉜 Tripo 모델 (2026.10.18 여성 무장 5명)

Tripo의 부품 내보내기(부품 40~90개, 부품마다 텍스처)는 다음 순서로 굽습니다.

1. `bake-parts.js`의 `__bakeParts(파일, 대역)`: 부품마다 기마 자세로 굽습니다. mixamo 뼈 이름 외에 CC식 뼈대(`Hip · L_Thigh · L_Upperarm …`, 채문희)도 mixamo 이름으로 읽고, 보조 뼈(Twist · ShareBone)는 위치는 쓰지 않고 가중치만 본 뼈로 넘깁니다.
   - 뼈대가 거꾸로 붙어 쓸 수 없는 모델(소교: 엉덩이뼈가 머리 위, 발뼈가 머리 장식에)은 대역(관은병)의 뼈대 · 가중치를 가장 가까운 점에서 빌립니다. 몸에서 멀리 떨어진 치맛자락 · 소매 끝은 전체에서 가장 가까운 점을 찾고(못 찾으면 땅바닥으로 늘어나던 문제), 목 위(얼굴 · 머리 장식)는 머리뼈 하나로 단단히 묶어 얼굴에 주름이 지지 않게 합니다.
2. `simplify.mjs 입력 출력 0.4 0.02`: meshoptimizer로 삼각형을 줄입니다(꼭짓점 · UV · 가중치는 그대로, 이음매 유지).
3. `assemble_parts.py 원본.glb 구운.json 출력.glb 1536 768`: 부품 텍스처를 한 장의 아틀라스(기본색 1536 · 법선 768)로 모읍니다. 칸 크기는 부품 넓이 몫 + 삼각형 몫(얼굴처럼 세밀한 부품일수록 크게), 머리 · 얼굴은 2배. UV 섬 바깥은 가장 가까운 섬 색으로 채워(bleed) 줄인 텍스처에서 섬 가장자리에 검은 금이 생기지 않게 합니다. 스카이라인 방식으로 채웁니다.

## 리깅 없는 모델 자동 리깅 (2026.10.18 소교 · 채문희 다시 만듦)

`autorig.py 원본.glb 리깅.glb 80000`: T자세 · 뼈대 없는 Tripo 모델(부품 내보내기)에 mixamo 뼈대를 세우고 가중치를 계산합니다.

- 몸 치수로 뼈 위치: 키(바닥 0), 팔 높이(몸통 바깥 점들의 높이 중앙값), 손끝(가장 먼 x), 다리 간격(발목 높이 점들), 나머지는 사람 비율.
- 가중치: 뼈 구간까지 거리로 가까운 두 뼈를 섞되, 팔 띠는 몸통에서 떼고, 머리 위는 통째로 머리뼈.
- 팔(어깨 바깥)은 거리 대신 어깨 → 손끝 위치(x)만으로: 팔꿈치 앞뒤 6%에서 위팔 → 아래팔로 부드럽게 넘기고, 손은 손목 몫 20%까지만(손가락 뼈가 없어 손이 통째로 꺾이므로). 가까운 구간으로 고르면 아래팔 중간이 지그재그로 꺾인다.
- 허리 아래 자락: 좌우는 x로 부드럽게 나누고 무릎 위는 허벅지 · 아래는 정강이를 따르며, 다리에서 멀리 퍼진 치맛단 · 뒤로 끌리는 자락은 엉덩이에 매달려 아래로 드리웁니다(다리를 따라 돌면 날개처럼 뻗는다).
- 원본이 너무 크면(채문희 원본 190만 삼각형 · 58MB) 리깅 전에 meshoptimizer로 8만 삼각형까지 줄입니다(`simplify_raw.mjs`).

그다음은 위와 같이 `__bakeParts(리깅.glb)` → `simplify.mjs 0.4` → `assemble_parts.py … 1536 0`(법선 텍스처 없음).

## 얼굴 화질: UV 섬 단위 아틀라스 (2026.10.18, 여성 무장 7명)

`assemble_islands.py 원본.glb 구운.s.json 출력.glb 1536 768 2.5`: `assemble_parts.py`는 부품 텍스처를 통째로(1024로 줄인 뒤) 붙여 얼굴처럼 작은 UV 섬이 뭉개지고 섬 가장자리에 금이 생긴다. 여기서는 UV 섬(이어진 삼각형 묶음)마다 원본 해상도에서 잘라 따로 배치하고(스카이라인), 머리 · 목 뼈를 따르는 섬은 2.5배 해상도로 넣는다. 섬마다 바깥을 그 섬 색으로만 채워(bleed) 이웃 섬 색이 번지지 않는다.

`simplify.mjs`는 머리 · 목 가중치가 큰 부품은 0.9 이상만 줄인다(코 · 눈가에 구멍이 나 뒤가 비치던 문제).

2차(같은 날): 머리 배율 4(축융은 깃털 머리장식이 커서 2.5), 섬 테두리 4px(멀리서 볼 때 밉맵이 이웃 섬을 섞어 코 · 볼에 금이 가던 문제), 얼굴 · 머리 섬은 법선 그림을 빼고(Tripo 법선 그림이 얼굴에 얼룩 · 조각 무늬를 만든다) 굽기 때 `RIGID=1 node bake2shot.mjs …`로 목 위를 머리뼈 하나에 단단히 묶는다(목 · 머리 가중치가 섞이면 말 탄 자세에서 얼굴이 비뚤어진다).

채문희 머리 비율(2026.10.18): `HEADSCALE=0.8,0.72,0.8 RIGID=1 node bake2shot.mjs cwj-rig.glb cai-wenji` — 머리뼈를 따르는 몫만큼 머리 관절 중심으로 가로 · 세로 · 앞뒤를 줄인다(`window.__headScale`).

다리(2026.10.18, autorig 4명 소교 · 초선 · 채문희 · 대교): 엉덩이에 매단 치맛자락은 말 위에서 서 있을 때 길이 그대로 곧게 내려가 말 배 아래로 빠졌다 → `DRAPE_SHIN=1`(기본)로 무릎 아래 자락은 정강이를 따른다. 다리가 긴 모델은 `LIMBFIT=1 node bake2shot.mjs …`로 허벅지 · 정강이를 기마 모델 길이에 맞춰(`window.__limbFit`) 발이 등자 높이에 온다.
